# 分身战斗原型设计 v0.1

## 1. 项目风格

- 类型：2D 横板 ARPG
- 风格：赛博锦衣卫
- 视觉方向：赛博朋克像素风，未来复古感
- 战斗参考：《苍翼：混沌效应》
- 原型目标：验证“分身能力 + 高机动短剑战斗”是否能形成清晰、爽快、有战术选择的战斗循环。

### 1.1 战斗气质参考

参考《苍翼：混沌效应》的方向：

- 高速横板战斗。
- 连段密度高，攻击衔接要顺。
- 位移、闪避、空中追击是战斗的一部分，不只是躲避工具。
- 技能应服务于连段、聚敌、浮空和收尾。
- 玩家需要经常在地面与空中之间切换。
- 分身能力要融入连段节奏，而不是作为独立大招存在。

原型阶段不追求完整的 roguelite 构筑系统，先验证单一流派“短剑 + 武士道 + 分身”的基础手感。

## 2. 输入约定

原型阶段以手柄输入为主。

| 输入 | 行为 |
| --- | --- |
| 左摇杆 / 十字键 | 移动、方向输入 |
| A | 跳跃 / 二段跳 |
| B | 闪避 / 冲刺 |
| X | 普通攻击 |
| Y | 技能 |
| RT | 分身能力修饰键 |
| RB | 诱饵分身组合键 |

## 3. 玩家基础能力

### 3.1 待机

玩家无输入时进入待机状态。

原型要求：

- 角色朝向保持最后一次移动方向。
- 可随时衔接移动、跳跃、攻击、闪避、分身。

### 3.2 移动

玩家可左右移动。

原型要求：

- 横向移动响应要快。
- 转向要清晰。
- 移动可衔接跳跃、普通攻击、冲刺和分身。

### 3.3 跳跃

玩家可以跳跃，并具有二段跳。

原型要求：

- 初始跳跃：从地面起跳。
- 二段跳：空中可再次跳跃一次。
- 落地后刷新二段跳次数。

### 3.4 闪避 / 冲刺

玩家可以进行短距离冲刺位移。

原型要求：

- 地面可冲刺。
- 武士道核心激活后，空中可闪避 1 段。
- 闪避成功时触发武士道强化效果。

## 4. 分身能力

分身是原型的核心能力。三种分身均通过 RT 组合键释放。

### 4.1 诱饵分身

输入：`RT + RB`

效果：

- 玩家在原地释放诱饵分身。
- 玩家同时向前冲刺位移。
- 诱饵分身吸引敌人注意。

用途：

- 脱身。
- 拉开距离。
- 制造反击窗口。
- 验证敌人仇恨转移机制。

原型规则：

- 诱饵分身不攻击。
- 诱饵分身有短暂存在时间。
- 敌人优先攻击诱饵，除非玩家重新造成威胁。

### 4.2 追击分身

输入：`RT + X`

效果：

- 向敌人释放一个追击分身。
- 分身自动攻击敌人。
- 分身存在期间，玩家再次按下 `RT` 时，与该分身交换位置。

用途：

- 远距离起手。
- 接近敌人。
- 改变站位。
- 制造连段延展。

原型规则：

- 不做锁定敌人系统，自动选择最近的敌人。
- 如果没有目标，分身向前短距离释放后消失。
- 追击分身进行短时间连击，不是单次攻击。
- 交换位置只能在分身有效期间触发。
- 交换位置后分身消失，或进入短暂残影消散表现。

### 4.3 协同分身

输入：`RT + Y`

效果：

- 在敌人身后释放一个协同分身。
- 协同分身模仿玩家攻击。
- 持续时间：2 秒。

用途：

- 夹击敌人。
- 强化连招。
- 短时间爆发。
- 提升战斗爽感。

原型规则：

- 优先出现在当前锁定 / 最近敌人的背后。
- 玩家普通攻击时，协同分身同步攻击。
- 协同分身不模仿技能，第一版只模仿普通攻击。
- 持续时间结束后消失。

## 5. 玩家战斗流派

原型流派结构：`武器 + 核心 + 技能`

第一版固定为：

- 武器：短剑
- 核心：武士道
- 技能：3 个方向派生技能

## 6. 武器：短剑

短剑定位：

- 攻速快。
- 连段灵活。
- 适合和分身联动。
- 单次攻击范围较短，需要通过位移、分身和挑飞制造输出机会。
- 更偏高速连段武器，而不是重攻击武器。

## 7. 核心：武士道

武士道定位：

- 鼓励精准闪避。
- 强化短时间反击。
- 提高空中机动性。

效果：

- 闪避成功后，强化下一次攻击。
- 获得空中闪避能力：空中可闪避 1 段。
- 闪避后刷新普攻衔接，使玩家可以继续进攻。

原型规则：

- 闪避成功指：闪避窗口内避开敌人攻击判定。
- 强化攻击只强化下一次普通攻击或冲刺攻击。
- 强化攻击改变伤害和特效，不改变基础动作。
- 强化攻击命中时应有明显反馈。

## 8. 基础普攻

### 8.1 地面普攻连段

输入：连续按 `X`

效果：

- 地面 4 段普攻连段。

原型规则：

- 每段攻击有独立位移、伤害和击退。
- 第 4 段作为收尾攻击，反馈更重。
- 闪避后可刷新普攻，使玩家继续连段或重新起手。

### 8.2 挑飞攻击

输入：`上方向 + X`

效果：

- 将敌人挑飞。

用途：

- 进入空中连段。
- 给协同分身创造输出窗口。

### 8.3 空中普攻连段

输入：空中连续按 `X`

效果：

- 空中 3 段普攻连段。
- 最后一段将敌人打落至地面。

原型规则：

- 空中普攻结束后，玩家必须下落。
- 空中普攻如果中断，攻击后摇结束且没有继续攻击时，玩家直接进入下落。
- 空中普攻中断后不能继续追加空中普攻，直到落地或通过指定机制刷新。
- 空中闪避可以重新获得空中攻击机会。

### 8.4 冲刺攻击

输入：冲刺过程中按 `X`

效果：

- 玩家向前突进攻击。

用途：

- 快速接近。
- 闪避成功后反击。
- 与追击分身换位后衔接攻击。

## 9. 技能

技能统一使用 `Y`，通过方向输入派生。

### 9.1 前方剑气

输入：`Y`

效果：

- 向前释放一道剑气。

用途：

- 中距离消耗。
- 打断敌人。
- 衔接追击分身。

### 9.2 空中斜下突刺

输入：空中 `下方向 + Y`

效果：

- 玩家斜向下冲刺。
- 命中敌人时将敌人击落。
- 玩家同时落地。

用途：

- 空中连段收尾。
- 快速回到地面。
- 将敌人压回地面战斗节奏。

### 9.3 斜上剑气

输入：`上方向 + Y`

效果：

- 斜向上发射剑气。
- 控住敌人。

用途：

- 防空。
- 延长浮空。
- 与挑飞攻击和协同分身配合。

## 10. 第一版战斗循环

推荐原型循环：

1. 玩家接近敌人。
2. 使用地面短剑连段建立基础手感。
3. 使用挑飞攻击进入空中连段。
4. 使用空中攻击或斜下技能收尾。
5. 敌人反击时，玩家通过闪避触发武士道。
6. 玩家使用强化攻击反打。
7. 根据战局使用三种分身：
   - 诱饵分身脱身。
   - 追击分身换位。
   - 协同分身爆发。

节奏目标：

- 玩家不应长时间等待敌人动作结束。
- 闪避成功后要能快速反打。
- 挑飞、空中连段、斜下收尾要形成清晰闭环。
- 分身释放后应能继续玩家当前攻势，而不是打断战斗节奏。

## 11. 原型优先级

### P0：必须完成

- 玩家移动、跳跃、二段跳。
- 地面闪避 / 冲刺。
- 地面 4 段普攻。
- 一个基础敌人。
- 命中、受击、击退反馈。
- 诱饵分身。

### P1：核心验证

- 追击分身。
- 追击分身换位。
- 协同分身。
- 武士道闪避成功判定。
- 闪避成功后强化攻击。
- 挑飞攻击。
- 空中 3 段普攻。

### P2：手感增强

- 冲刺攻击。
- 三个技能。
- 空中闪避。
- 空中攻击中断后强制下落。
- 分身视觉差异。

## 12. 已确认设计决定

- 不做锁定敌人系统，攻击与分身目标自动选择最近敌人。
- 追击分身自动攻击为短时间连击。
- 协同分身不模仿技能，只模仿普通攻击。
- 武士道强化攻击改变伤害和特效，不改变基础动作。
- 空中闪避可以重新获得空中攻击机会。
